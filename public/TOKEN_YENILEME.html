🔴 Facebook & Instagram Token Yenileme Rehberi

⚠️ HATA MESAJLARI:
• Facebook: "Cannot call API for app... on behalf of user..."
• Instagram: "API access blocked"

SEBEP: Token süresi dolmuş veya yanlış token tipi kullanılıyor!

📘 ADIM 1: Graph API Explorer'a Git

https://developers.facebook.com/tools/explorer/

🔑 ADIM 2: Token Ayarları

  1. Facebook App'inizi seçin (üstteki dropdown)
  2. "User or Page" → "Get Page Access Token" seçin
  3. Sayfanızı seçin: "SocialPublish2"
  4. İzinler seçin:
    • ✅ pages_show_list
    • ✅ pages_read_engagement
    • ✅ pages_manage_posts
    • ✅ pages_manage_engagement
    • ✅ instagram_basic
    • ✅ instagram_content_publish
  5. "Generate Access Token" butonuna tıklayın

📋 ADIM 3: Page Access Token'ı Al

Graph API Explorer'da şu sorguyu çalıştırın: me/accounts?fields=name,id,access_token,instagram_business_account

"Submit" butonuna tıklayın!

Sonuçta göreceksiniz: { "data": [ { "name": "SocialPublish2", "id": "855462937657363", "access_token": "EAAhLRZC...UZUN_TOKEN...", ← BU! "instagram_business_account": { "id": "123456789" ← Instagram hesap ID'si } } ] }

🚂 ADIM 4: Railway'e Ekle

Railway → Settings → Variables: FACEBOOK_ACCESS_TOKEN=EAAhLRZC...YENİ_TOKEN... FACEBOOK_PAGE_ID=855462937657363 INSTAGRAM_BUSINESS_ACCOUNT_ID=123456789 ← Yeni!

⚠️ INSTAGRAM İÇİN EK KONTROL

  1. Facebook Sayfanızı Instagram Business hesabına bağladınız mı?
    • Facebook Sayfa Ayarları → Instagram → Hesap Bağla
  2. Instagram hesabı "Professional Account" (İşletme Hesabı) mı?
    • Instagram → Ayarlar → Hesap Türü → İşletme Hesabına Geç
✅ KONTROL: Yeni token'ı aldıktan sonra tarayıcıda test edin:
https://graph.facebook.com/v21.0/855462937657363?fields=name,access_token&access_token=YENİ_TOKEN

Başarılıysa: { "name": "SocialPublish2", "id": "855462937657363" }

🎯 ÖZET

  1. ✅ Graph API Explorer → Get Page Access Token
  2. ✅ İzinleri seç (pages_manage_posts + instagram_content_publish)
  3. ✅ me/accounts sorgusu çalıştır
  4. ✅ access_token ve instagram_business_account ID'sini kopyala
  5. ✅ Railway Variables'a ekle
  6. ✅ Redeploy
📌 NOT: Token'lar 60 günde bir yenilenir. Bu normal!
💡 İPUCU: "Long-lived token" kullanırsanız 60 gün sürer.
🔒 GÜVENLİK: Token'ları asla paylaşmayın!
